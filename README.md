# 🗼 rapp-tower — mission control for the RAPP ecosystem

The repo where AI-first sessions **land**. Full command over the estate —
the train, the shapes, the standards, every checkout's role and touch
rules — without squatting in a production repo. Nothing here ships; the
tower commands the railroad, it is never on the tracks.

Start every cross-ecosystem session here:

| Surface | What it answers |
|---|---|
| `CLAUDE.md` | The command brief: estate map, registry, iron laws |
| `FLIGHT_RULES.md` | Pre-decided emergency responses (FR-1…FR-9) |
| `GO-NOGO.md` | Grail-release poll + post-release closeout |
| `RECOVERY.md` | If this laptop dies today |
| `tools/checkouts.sh` | Checkout truth + grail tripwire + backup age + holds |
| `tools/triage.sh` | Service identity/health/auth (port-open ≠ healthy) |
| `tools/train.sh` | Train position: what's attested at every ring |
| `tools/pages.sh` | Pages-live vs origin (installers are Pages-only) |
| `tools/release_gate.sh` | GO/NO-GO before `grail_gate.py` |
| `tools/drift.sh` | Drift-governance oracle surface |
| `tools/backup-memory.sh` | Sole-copy state archiver — step 0 of surgery |
| `tools/backup-status.sh` | Machine durability board |
| `tools/holds.sh` | Parallel-session holds protocol |
| `tools/leakcheck.sh` | Publishing-boundary gate (private denylist) |
| `work/` | The decision log — the ecosystem's history |

Private by design: work products may reference contexts that never flow to
the public estate (iron law 7; `sensitive/denylist.json` is the enforced
form of that promise).
